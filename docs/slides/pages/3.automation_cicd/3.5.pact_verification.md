# Pact Verification: local artifact vs Broker

<div class="grid grid-cols-2 gap-6 mt-6">
  <div class="p-4 bg-cyan-50 border border-cyan-200 rounded-xl">
    <div class="text-sm font-bold text-cyan-700">Cách 1: Local artifact</div>
    <div class="text-sm text-gray-600 mt-2">Provider verification có thể chạy bằng artifact local qua <code>PACT_FILE</code>.</div>
    <div class="text-xs text-gray-500 mt-2">Phù hợp khi chạy lab, demo hoặc CI artifact handoff.</div>
  </div>
  <div class="p-4 bg-blue-50 border border-blue-200 rounded-xl">
    <div class="text-sm font-bold text-blue-700">Cách 2: Broker / Pactflow</div>
    <div class="text-sm text-gray-600 mt-2">Khi nâng cấp lên Broker/Pactflow thì dùng <code>PACT_BROKER_URL</code> + token để publish và verify xuyên CI.</div>
    <div class="text-xs text-gray-500 mt-2">Phù hợp khi nhiều team cần compatibility matrix và deployment gate thật.</div>
  </div>
</div>

<div class="mt-5 p-4 bg-gray-50 border border-gray-200 rounded-lg text-sm text-gray-600">
  Repo hiện hỗ trợ cả hai đường đi. Nhờ vậy nhóm có thể demo bằng artifact cục bộ trước, rồi mở rộng sang mô hình Broker khi muốn scale quy trình.
</div>
