# Các cơ chế xác thực phổ biến

<div class="grid grid-cols-2 lg:grid-cols-3 gap-4 mt-6">
  <div v-click class="p-4 bg-gray-50 border border-gray-200 rounded-2xl">
    <div class="text-sm font-mono tracking-widest text-cyan-600 uppercase">Basic Auth</div>
    <div class="mt-2 text-sm text-gray-600">Base64 `username:password`, đơn giản nhưng chỉ nên dùng khi có HTTPS.</div>
  </div>
  <div v-click class="p-4 bg-gray-50 border border-gray-200 rounded-2xl">
    <div class="text-sm font-mono tracking-widest text-blue-600 uppercase">API Key</div>
    <div class="mt-2 text-sm text-gray-600">Khóa tĩnh cho client, thường đặt ở header để tránh lộ trong URL.</div>
  </div>
  <div v-click class="p-4 bg-gray-50 border border-gray-200 rounded-2xl">
    <div class="text-sm font-mono tracking-widest text-indigo-600 uppercase">Bearer JWT</div>
    <div class="mt-2 text-sm text-gray-600">Token 3 phần `Header.Payload.Signature`, phù hợp cho auth stateless.</div>
  </div>
  <div v-click class="p-4 bg-gray-50 border border-gray-200 rounded-2xl">
    <div class="text-sm font-mono tracking-widest text-emerald-600 uppercase">OAuth 2.0</div>
    <div class="mt-2 text-sm text-gray-600">Cơ chế ủy quyền cho app thứ ba, phổ biến với Authorization Code và Client Credentials.</div>
  </div>
  <div v-click class="p-4 bg-gray-50 border border-gray-200 rounded-2xl">
    <div class="text-sm font-mono tracking-widest text-amber-600 uppercase">mTLS</div>
    <div class="mt-2 text-sm text-gray-600">Client và server đều có chứng chỉ, phù hợp machine-to-machine hoặc microservices nội bộ.</div>
  </div>
  <div v-click class="p-4 bg-gray-50 border border-gray-200 rounded-2xl">
    <div class="text-sm font-mono tracking-widest text-rose-600 uppercase">Custom Timestamp</div>
    <div class="mt-2 text-sm text-gray-600">Bearer ISO-8601 của Product Service, dùng như cơ chế demo cho toàn bộ endpoint.</div>
  </div>
</div>

<div v-click class="mt-5 p-4 bg-cyan-50 border border-cyan-200 rounded-lg text-sm">
  <strong class="text-cyan-700">Trong seminar này:</strong> Product Service dùng custom bearer timestamp, nên mọi endpoint đều cần `Authorization` header hợp lệ.
</div>
