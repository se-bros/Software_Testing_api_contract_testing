# API có Authentication vs Authorization

<div class="grid grid-cols-2 gap-8 mt-6">
  <div>
    <h3 class="text-lg font-bold text-gray-600 mb-3">AuthN vs AuthZ</h3>
    <div class="space-y-2 text-sm text-gray-600">
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span><strong>Authentication (AuthN)</strong>: xác minh danh tính người dùng</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span><strong>Authorization (AuthZ)</strong>: kiểm tra quyền hạn của danh tính đó</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span><strong>No Auth</strong> chỉ phù hợp với endpoint công khai, ít nhạy cảm</span>
      </div>
    </div>
  </div>
  <div>
    <h3 class="text-lg font-bold text-blue-700 mb-3">Nhận diện nhanh</h3>
    <div class="space-y-3 text-sm">
      <div v-click class="p-3 bg-cyan-50 border border-cyan-200 rounded-lg">
        <strong class="text-cyan-700">AuthN</strong>
        <div class="text-gray-500 mt-1">Hỏi "bạn là ai?" trước khi vào hệ thống</div>
      </div>
      <div v-click class="p-3 bg-blue-50 border border-blue-200 rounded-lg">
        <strong class="text-blue-700">AuthZ</strong>
        <div class="text-gray-500 mt-1">Hỏi "bạn được phép làm gì?" sau khi đã biết danh tính</div>
      </div>
      <div v-click class="p-3 bg-indigo-50 border border-indigo-200 rounded-lg">
        <strong class="text-indigo-700">Product Service</strong>
        <div class="text-gray-500 mt-1">Mọi endpoint đều yêu cầu `Authorization: Bearer ISO-8601 timestamp`.</div>
        <div class="mt-2 font-mono text-xs bg-white p-2 rounded border border-indigo-100">
          Authorization: Bearer 2026-07-15T10:00:00.000Z
        </div>
        <div class="mt-1 text-xs text-gray-500">
          Token hợp lệ trong vòng 1 giờ và không ở tương lai → sai format hoặc hết hạn sẽ trả `401`.
        </div>
      </div>
    </div>
  </div>
</div>

<div class="footnotes">
<div class="fn-item"><sup>1</sup><strong>Bearer ISO-8601</strong> — Token dạng timestamp theo chuẩn ISO-8601 (vd: 2026-07-15T10:00:00.000Z), hợp lệ trong 1 giờ và dùng như custom bearer token trong Product Service.</div>
</div>
