# Postman — Tổng quan

<div class="grid grid-cols-2 gap-8 mt-6">
  <div>
    <h3 class="text-lg font-bold text-cyan-700 mb-3">Postman là gì</h3>
    <div class="space-y-2 text-sm text-gray-600">
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span>Nền tảng kiểm thử API để gửi request, xem response và lưu test case theo <span class="text-cyan-700 font-semibold">Collection</span> (nhóm request)</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span>Hỗ trợ Desktop App, Web và <strong>VS Code Extension</strong></span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span>Phù hợp cho test thủ công, test lặp lại và tự động hóa mức cơ bản trong cùng một công cụ</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-cyan-600 font-bold">•</span>
        <span>Giúp chuẩn hóa quy trình từ thử API nhanh đến viết assertion và chạy test theo môi trường</span>
      </div>
    </div>
  </div>

  <div>
    <h3 class="text-lg font-bold text-blue-700 mb-3">Các khái niệm chính</h3>
    <div class="space-y-2 text-sm text-gray-600">
      <div v-click class="flex gap-2">
        <span class="text-blue-600 font-bold">•</span>
        <span><strong class="text-blue-700">Collection</strong> — gom nhóm request theo chức năng hoặc theo user flow</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-blue-600 font-bold">•</span>
        <span><strong class="text-blue-700">Environment</strong> — biến theo môi trường như baseUrl, token, id</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-blue-600 font-bold">•</span>
        <span><strong class="text-blue-700">Variable</strong> — giá trị động dùng lại giữa nhiều request</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-blue-600 font-bold">•</span>
        <span><strong class="text-blue-700">Pre-request Script</strong> — chuẩn bị dữ liệu trước khi gửi request</span>
      </div>
      <div v-click class="flex gap-2">
        <span class="text-blue-600 font-bold">•</span>
        <span><strong class="text-blue-700">Test Script</strong> — <strong>Assertion</strong> là câu lệnh kiểm tra chạy sau response</span>
      </div>
    </div>
  </div>
</div>

<div v-click class="mt-5 p-4 bg-gray-50 border border-gray-200 rounded-lg text-sm text-gray-600">
  Postman không chỉ là nơi gửi request thủ công. Điểm mạnh thật sự nằm ở <strong>Collection</strong>, <strong>Environment</strong> và script để biến các request rời rạc thành test suite có thể tái sử dụng.
</div>

<div class="footnotes">
<div class="fn-item"><sup>1</sup><strong>Assertion</strong> — Câu lệnh kiểm tra tự động chạy sau mỗi request, ví dụ status = 200.</div>
</div>
