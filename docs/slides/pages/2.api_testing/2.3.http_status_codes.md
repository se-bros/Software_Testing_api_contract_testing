# Đọc kết quả API bằng status code

<div class="grid grid-cols-3 gap-3 mt-3">
  <div v-click class="p-3 bg-emerald-50 border border-emerald-200 rounded-xl">
    <div class="text-3xl font-black text-emerald-600">2xx</div>
    <div class="mt-1 text-base font-bold text-emerald-800">Success</div>
    <div class="mt-1 text-xs text-gray-600">200 OK, 201 Created, 204 No Content</div>
  </div>
  <div v-click class="p-3 bg-amber-50 border border-amber-200 rounded-xl">
    <div class="text-3xl font-black text-amber-600">4xx</div>
    <div class="mt-1 text-base font-bold text-amber-800">Client Error</div>
    <div class="mt-1 text-xs text-gray-600">400, 401, 403, 404, 409, 422, 429</div>
  </div>
  <div v-click class="p-3 bg-rose-50 border border-rose-200 rounded-xl">
    <div class="text-3xl font-black text-rose-600">5xx</div>
    <div class="mt-1 text-base font-bold text-rose-800">Server Error</div>
    <div class="mt-1 text-xs text-gray-600">500, 502, 503, 504</div>
  </div>
</div>

<div v-click class="mt-3 p-3 bg-gray-50 border border-gray-200 rounded-lg text-xs text-gray-600">
  1xx và 3xx vẫn thuộc chuẩn HTTP, nhưng khi trình bày API Testing thì nhóm tập trung vào 2xx, 4xx và 5xx vì đây là nhóm xuất hiện nhiều nhất trong test thực tế.
</div>

<div class="footnotes">
<div class="fn-item"><sup>1</sup><strong>Tip</strong> — Khi assert API, nên kiểm tra cả status code, body schema và error message, không chỉ nhìn vào `200`.</div>
</div>
