# API là gì?

**API** (Application Programming Interface): giao diện lập trình cho phép các hệ thống giao tiếp.

**REST API**: dùng HTTP protocol — method, URL, headers, body.

<div class="mt-4 p-3 bg-gray-50 border border-gray-200 rounded-lg font-mono text-sm">
  <div class="text-gray-500">Request: <span class="text-cyan-700">Method + URL + Headers + Body</span></div>
  <div class="text-gray-500 mt-1">Response: <span class="text-blue-700">Status Code + Headers + Body</span></div>
</div>

<div class="grid grid-cols-2 gap-8 mt-5">
  <div>
  <h3 class="text-lg font-bold text-cyan-700 mb-2">HTTP Methods</h3>

| Method   | Ý nghĩa           | Ví dụ                |
| -------- | ----------------- | -------------------- |
| `GET`    | Đọc dữ liệu       | `GET /products`      |
| `POST`   | Tạo mới           | `POST /products`     |
| `PUT`    | Cập nhật toàn bộ  | `PUT /product/10`    |
| `PATCH`  | Cập nhật một phần | `PATCH /product/10`  |
| `DELETE` | Xóa               | `DELETE /product/10` |

  </div>
  <div>
  <h3 class="text-lg font-bold text-blue-700 mb-2">Nguyên tắc thiết kế REST</h3>
  <div class="space-y-2 text-xs">
    <div v-click class="p-2.5 bg-cyan-50 border border-cyan-200 rounded-lg">
      <strong class="text-cyan-700">Statelessness</strong>
      <div class="text-gray-500 mt-0.5">Server không lưu trạng thái phiên làm việc; mỗi request phải tự mang đầy đủ thông tin xác thực và dữ liệu.</div>
    </div>
    <div v-click class="p-2.5 bg-indigo-50 border border-indigo-200 rounded-lg">
      <strong class="text-indigo-700">Safety & Idempotency</strong>
      <div class="text-gray-500 mt-0.5">GET chỉ đọc (safe). PUT, DELETE, GET có thể gọi lặp lại nhiều lần mà không thay đổi tác động phụ (idempotent).</div>
    </div>
  </div>
  </div>
</div>
