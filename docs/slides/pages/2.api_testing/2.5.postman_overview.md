# Postman — Tổng quan

<div class="grid grid-cols-3 gap-6 mt-6">
  <div>
  <h3 class="text-lg font-bold text-cyan-700 mb-3">Postman là gì</h3>
  <v-clicks>

  - Nền tảng kiểm thử API **phổ biến nhất**
  - Hỗ trợ Desktop App, Web, và **VS Code Extension**
  - Miễn phí cho cá nhân & nhóm nhỏ (≤ 3 người)
  - **Charge phí doanh nghiệp khi:**
    - Team size > 3 thành viên
    - Vượt quota Cloud (Mock, Monitor...)

  </v-clicks>
  </div>

  <div>
  <h3 class="text-lg font-bold text-blue-700 mb-3">Các khái niệm chính</h3>
  <v-clicks>

  - **Collection** — Gom nhóm request
  - **Environment** — Biến môi trường
  - **Variable** — Giá trị động dùng lại
  - **Pre-request Script** — Chạy trước request
  - **Test Script** — Assertion<sup>1</sup> chạy sau response

  </v-clicks>
  </div>

  <div>
  <h3 class="text-lg font-bold text-indigo-700 mb-3">Tính năng nâng cao</h3>
  <v-clicks>

  - **Collection Runner** — Chạy chuỗi request
  - **Data-driven** — Chạy test với file (CSV/JSON)
  - **Newman** — CLI runner cho CI/CD
  - **Monitor** — Test định kỳ tự động
  - **Mock Server** — Giả lập API nhanh

  </v-clicks>
  </div>
</div>

<div class="footnotes mt-8">
<div class="fn-item text-[11px]"><sup>1</sup><strong>Assertion</strong> — Câu lệnh kiểm tra tự động (vd: status = 200) chạy sau mỗi request.</div>
</div>
