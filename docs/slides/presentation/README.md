# Presentation Scripts

Bộ script thuyết trình được tách theo từng phần của deck để dễ luyện tập và phân công người nói. Mỗi file chứa ghi chú ngắn theo từng slide, bám sát nội dung trong `docs/slides/pages`.

## Cấu trúc

| File | Phạm vi |
| --- | --- |
| [1.intro.md](./1.intro.md) | Slide 1-3: Mở đầu và mục tiêu |
| [2.api_testing.md](./2.api_testing.md) | Slide 4-16: API Testing, Postman, REST Client, Product Service |
| [3.automation_cicd.md](./3.automation_cicd.md) | Slide 17-21: Newman và CI/CD |
| [4.contract_testing.md](./4.contract_testing.md) | Slide 22-28: Contract Testing và Pact |
| [5.demo_pact.md](./5.demo_pact.md) | Slide 29-35: Demo Pact và breaking change |
| [6.ai_testing.md](./6.ai_testing.md) | Slide 36-38: AI-assisted testing |
| [7.summary.md](./7.summary.md) | Slide 39-46: Tổng kết, Q&A, cảm ơn |

## Cách dùng

- Đọc theo đúng thứ tự slide để giữ mạch trình bày.
- Mỗi slide chỉ cần nắm 2-3 ý chính, không cần đọc nguyên văn.
- Nếu có thời gian, thêm ví dụ từ repo hoặc video demo để câu chuyện tự nhiên hơn.
